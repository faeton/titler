# Running on n5 (TrueNAS SCALE, Linux x86_64)

n5 is the home NAS (TrueNAS SCALE, Debian-based, no apt on the host).
The repo lives at `~/work/titler` (`~` = `/mnt/flash/home/faeton`).

## Setup (what was done, 2026-10-24)

```bash
cd ~/work
# No GitHub SSH key on n5 — clone over HTTPS, `gh` is logged in
git clone https://github.com/faeton/titler.git
cd titler

# Node v24 + pnpm come from nvm
pnpm install --frozen-lockfile

# `python3 -m venv` fails on TrueNAS (no ensurepip) — use uv instead
uv venv --seed -p 3.11 .venv
uv pip install -p .venv/bin/python faster-whisper opencv-python-headless numpy

# .env (TITLER_BEARER_TOKEN, only used by api/server.js) copied from m3max
```

Smoke test passed: server boots, `/projects` and `/inbox` return 200.

## Differences from the Mac

| Area | Mac (m3max) | n5 |
|---|---|---|
| Whisper | mlx-whisper on Apple GPU | mlx unavailable → `faster-whisper` on **CPU** |
| ffmpeg | Homebrew build w/ libass | `~/.local/bin/ffmpeg` (has `ass`/`subtitles` filters) |
| Fonts | Arial / Arial Black present | **missing** — libass silently substitutes |
| Encoder | `libx264` | `libx264` (works; VAAPI available, see below) |

## What's still needed

- **Fonts.** `server/src/assGen.ts` hardcodes `Arial Black` (Bold) and
  `Arial` (Clean, Focus). Drop the `.ttf` files into `~/.local/share/fonts`
  and run `fc-cache -f`. Check with `fc-list | grep -i arial`.
- **Whisper speed.** Default faster-whisper model is `large-v3` — very slow
  on CPU. Tune via env:
  - `TITLER_WHISPER_BACKEND=faster`
  - `TITLER_WHISPER_MODEL=small` (or `medium`)
  - `TITLER_WHISPER_DEVICE` (default `auto`), `TITLER_WHISPER_COMPUTE_TYPE` (default `int8`)
- **esbuild build script** was skipped by pnpm (`pnpm approve-builds` if it
  ever matters). tsx and vite run fine without it.
- **Remotion render path** (`server/src/render.ts`) needs headless Chrome
  plus its system libs — not tested on n5. The ffmpeg render path is the
  main one.
- **Network.** Server binds `0.0.0.0:7777` with no auth. Keep it on
  LAN/Tailscale, don't expose it publicly.

## TODO: use the iGPU (investigate + benchmark)

n5 has no NVIDIA card but does have an **AMD Radeon 890M** iGPU (Strix
Point). `/dev/kfd` (ROCm) and `/dev/dri/renderD128` are present, and this
GPU was already tuned for Ollama on this box, so the stack partly exists.

- **Transcription on GPU.** CTranslate2 (faster-whisper) has no stock ROCm
  wheel. Options to try: a ROCm build of CTranslate2, `whisper.cpp` with
  Vulkan or HIP, or whatever Ollama's ROCm setup already provides. Benchmark
  against CPU `small`/`medium` on the same clip (`bench_mac/` on m3max has
  reference timings).
- **Encoding on GPU.** `~/.local/bin/ffmpeg-hw` is an ffmpeg wrapper with
  VAAPI on the 890M (bundles libva 2.24 because TrueNAS ships 2.17). Try
  `h264_vaapi` in place of `libx264` in `server/src/ingest.ts` and
  `server/src/renderFfmpeg.ts`. Note that the `ass` filter runs on the CPU,
  so frames have to be uploaded with `hwupload` after the subtitles are
  burned in.
- The wrapper needs `render` group access to `/dev/dri`. `faeton` isn't in
  that group right now, so check permissions first.
